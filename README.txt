# Deepak Prajapati Portfolio

## Upload to GitHub Pages

1. Create a new **Public** GitHub repository.
2. Upload everything inside this folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Click **Save**.

## Before publishing

Replace:
- `images/deepak.jpg` with your real photo.
- `files/Deepak-Prajapati-CV.pdf` with your real CV.
- `your-email@example.com` with your email.
- `+977-XXXXXXXXXX` with your phone number.
- The social-media URLs in `index.html` with your real profiles.

## Login

The login screen is a front-end visual gate. It is not real authentication/security. The **Enter as Guest** button opens the portfolio directly.
